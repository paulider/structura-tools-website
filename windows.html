How Windows works

Configure. Place. Edit. Reuse.

Windows removes the repetitive work behind architectural window modelling while keeping the result controllable throughout production.

01 — Configure

Define the window

Set dimensions, leaves, opening type and the main architectural parameters.

One definition, complete system.
02 — Generate

Build the assembly

Create frames, glass, hardware and the coordinated window geometry.

No component-by-component modelling.
03 — Place

Insert into the wall

Position the window in context and resolve the real architectural opening.

Window and opening work together.
04 — Shapes

Go beyond rectangles

Work with rectangular and arched configurations for more realistic architectural cases.

Built for real architecture.
05 — Reuse

Clone configured windows

Reuse a finished configuration elsewhere in the model without starting again.

Repeat the system, not the work.
06 — Iterate

Edit and regenerate

Keep working when dimensions or design decisions change.

Designed for production iteration.
