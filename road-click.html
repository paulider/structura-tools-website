Road Click

A network system, not a single road command.

The product is designed around persistent network logic so roads, intersections, profiles and urban elements remain part of one editable system.

Point-to-point roads

Draw roads directly inside SketchUp using an interactive point workflow.

Connected topology

Maintain nodes and segments as a coherent road network instead of isolated geometry.

Intersections

Build junction logic around the network rather than manual geometry cleanup.

Profiles

Configure road sections, sidewalks and lane-oriented geometry.

Markings

Support center, edge and road-marking workflows as part of generated output.

Urban details

Add configurable road-side elements as part of the generated urban network.

Terrain adaptation is not part of the current Road Click Early Access. Terrain-conforming road generation is reserved for a separate Structura product or a future Road Click 2.0.
