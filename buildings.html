How Buildings works

Select. Style. Generate. Repeat.

Create detailed, varied architecture directly inside SketchUp — from a single building to an entire urban block.

01 — Select the footprints

Select the footprints

Choose one or multiple building footprints directly inside SketchUp.

One building or an entire block.
02 — Choose a building style

Choose a building style

Select the architectural style that fits the project. Residential, mixed-use or office presets define the character and basic rules of the building.

Start with a style. Make every building different.
03 — Adjust the design

Adjust the design

Control the main building parameters and choose how much variation you want. Use Subtle, Balanced or Strong variation while keeping every result within the selected architectural style.

Controlled variety, not random noise.
04 — Generate the buildings

Generate the buildings

Buildings creates the complete architecture from the selected footprints. Massing, floors, façades, windows, balconies and roofs are generated automatically according to the chosen style.

From footprint to building in seconds.
05 — Build at city scale

Build at city scale

Generate multiple buildings at once and create varied urban environments without modelling every façade individually. Change the configuration and regenerate whenever the project evolves.
