Troubleshooting

Start with the environment.

Many plugin problems are version, installation or library-state issues. Capturing those first makes support substantially faster.

01

Restart SketchUp

Confirm the issue survives a clean application restart.

02

Confirm versions

Note SketchUp, Structura product, OS and renderer versions.

03

Check library

Verify required libraries are installed and current.

04

Reproduce cleanly

Reduce the issue to the smallest repeatable workflow possible.

05

Collect logs

Use the product Logs button or the documented log location.

06

Capture screenshot

Include the relevant SketchUp view and any visible error message.

Bug report

Send reproducible information.

A useful report should contain the data below. This is especially important once Floor & Wall creates higher support volume.

ProductFloor & Wall / Windows / Road Click / Buildings / other
Structura versionExact public version
SketchUpExact SketchUp version
SystemOS and renderer version when relevant
ReproductionNumbered steps that consistently cause the issue
AttachmentsLog file + screenshot + SKP only when needed to reproduce
